# 侧栏入口开关

在「设置」中增加一个「侧栏入口管理」分区，用独立开关逐项控制左侧栏导航入口的显示与隐藏。

## 使用

打开 **设置 → 侧栏入口管理**，会看到 8 个开关：

- 插件、插件市场、DeepSeek 网页版、自动化任务、智能体、技能中心、SSH、更多

关闭某个开关即隐藏对应入口；「全部显示」可一键恢复。偏好保存在浏览器本地，刷新后仍生效。

## 说明

- 隐藏只作用于左侧栏的显示，不会卸载相关插件或影响其功能。
- 入口按可见文字匹配（中英文标签都覆盖），切换界面语言后仍然有效。
- 部分入口由第三方插件提供，插件延迟加载时会自动补隐藏。

## 局限

- 按可见文字匹配，若某个插件使用了同名的自定义标签，可能一并隐藏。
- 隐藏"更多"会同时收起其菜单里的未固定入口与创建插件入口。
